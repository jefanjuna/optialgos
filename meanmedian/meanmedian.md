Write a Python function mean_and_median(num_list) that takes a list of floating point numbers and:

    returns a tuple where the first element is the mean and the second is the median
    uses built-in Python functions like sum(), len(), and sorted() to simplify the logic
    returns (None, None) if the input list is empty.

Feel free to use built-in Python functions / methods.

Examples:

    mean_and_median([1.0, 2.0, 3.0]) returns (2.0, 2.0)
    mean_and_median([10.0, 20.0, 30.0, 40.0]) returns (25.0, 25.0)
